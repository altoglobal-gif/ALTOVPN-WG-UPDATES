# ALTOVPN-WG V.2026.31.0.2 Beta

Responsive Settings layout update for the Windows desktop client.

## Highlights

- Settings follows the available Main Window size with two columns at the supported minimum and three columns on wider windows.
- The locked Settings surface fits without an internal scrollbar at `920x680`.
- Short-window spacing is compacted without changing update, system, or protected-policy behavior.
- Unlocked Admin Mode receives a focused layout so protected controls remain usable.
