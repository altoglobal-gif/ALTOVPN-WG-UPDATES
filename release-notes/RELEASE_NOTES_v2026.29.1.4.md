# ALTOVPN-WG V.2026.29.1.4

Corrective SSH pivot rescan and remote MAC/manufacturer release.

## Fixed

- **Trust & Scan** now performs a bounded CIDR sweep from the selected SSH device instead of stopping after static inventory.
- Platform selection is automatic for Linux/Unix, MikroTik RouterOS, and Windows OpenSSH.
- Remote Linux neighbor, MikroTik ARP, and Windows `Get-NetNeighbor` results are merged into the client list.
- MAC Address and IEEE OUI Manufacturer values are populated when the remote account can read its neighbor table.
- Added **Scan again through SSH** with fresh credentials and host-key confirmation for every run.

## Security

- Pivot targets are derived only from the previously validated VPN CIDR.
- Every pivot scan is capped at 256 IPv4 targets.
- Only normalized IP addresses generated by native code enter fixed remote command templates.
- Credentials remain in native memory for one operation and are never stored or sent to the Web UI.
